# Project guide

Next.js 16 App Router portfolio + Markdown blog (SSG, deployed on Vercel).

## Commands

- `npm run dev` — custom wrapper (`scripts/dev.mjs`): optimizes images, syncs blog image folders, starts watchers, then runs `next dev`. Use this; plain `next dev` skips the image pipeline.
- `npm run build` — the `prebuild` step runs `scripts/optimize-images.mjs`. Don't substitute `npx next build`.
- `npm run lint` — ESLint flat config (`eslint.config.mjs`).
- `npx tsc --noEmit` — the only typecheck; there is no `typecheck` script.
- No test suite: Playwright is installed but unused.
- `npm run optimize-images` / `npm run sync-blog` — regenerate artifacts manually.

## Layout

- `app/` — App Router routes (root `app/`, not `src/app/`).
- `src/features/{blog,portfolio}/` — feature logic, data, components.
- `src/components/` — shared UI; `src/components/common/Image.tsx` is the project's image component.
- `content/blog/<slug>.md` — posts; `content/.cache/ogp-cache.json` — committed OGP cache.
- `public/images/` — source images; `public/images/optimized/` — generated WebP (committed).
- `scripts/` — dev/build image + blog sync pipeline.
- Alias `@/*` → `src/*`; root `app/` files import from `src/` via `@/`.

## Next.js 16

- Dynamic `params` are Promises: `const { slug } = await params` in pages, `generateMetadata`, and image routes.
- Fonts load via `next/font/google`, except OG images: `app/blog/[slug]/opengraph-image.tsx` reads bundled `public/fonts/*.ttf` to avoid build-time Google Fonts fetches (this previously timed out on Vercel). Don't reintroduce network font fetches there.

## Images (main gotcha)

- Add originals under `public/images/**` and reference the original path in Markdown (`/images/blog/<slug>/foo.jpg`) or data files. The pipeline generates `-thumb` 480, `-medium` 800, `-large` 1280 WebP variants.
- `scripts/optimize-images.mjs` also writes `src/generated/image-manifest.json` with each variant's actual width. `src/lib/imageVariants.ts` uses it for `srcset` descriptors, because small originals are not upscaled and fixed `480w/800w/1280w` labels would shrink images on high-DPR phones. Don't edit the manifest by hand.
- `getPostData` (rehype plugin) and `src/components/common/Image.tsx` rewrite `/images/...` to `/images/optimized/...`; don't reference `/images/optimized` paths by hand.
- Never edit `public/images/optimized/**` manually — it is generated by `scripts/optimize-images.mjs`, and orphaned files are deleted automatically.
- `next.config.ts` sets `images.unoptimized`, so use `Image` from `@/components/common/Image`, not `next/image`.
- `public/images/blog/<slug>/` is auto-created/removed to match `content/blog/<slug>.md` (`sync-blog-folders.mjs`). Only `common/` is preserved, so don't store shared images inside a post folder.

## Blog content

- Frontmatter: `title`, `date` (YYYY-MM-DD), optional `tags` as a YAML array. Non-array, empty, or non-string tags throw during build.
- Enabled Markdown: GFM, definition lists, GitHub alerts (`> [!NOTE]`), KaTeX (`$...$`, `$$...$$`), Mermaid, `[card](url)` OGP cards, pretty-code highlighting.
- `[card](url)` fetches OGP metadata at render/build (4s timeout) and caches in `content/.cache/ogp-cache.json`; delete that entry to refresh a card.
- Headings get `id`s from `rehype-slug`; `getPostData` collects `h2`s into `PostData.toc`, rendered by `src/components/blog/TableOfContents.tsx` (fixed left, 1080px+ only, hidden when fewer than 2 `h2`s).

## Conventions

- UI copy and comments are mostly Japanese; keep that style.
- Tailwind CSS v4 via `@tailwindcss/postcss`; no `tailwind.config.*`. Theme and blog styles live in `app/globals.css`.
- Site URL comes from `NEXT_PUBLIC_SITE_URL` (default `https://canooopus-me.vercel.app`).
- `CLAUDE.md` just imports `@AGENTS.md`; keep this file as the single source of truth.
- The Next.js block above is rewritten by `next dev`; put project notes outside it.
- A code-review skill lives at `.agents/skills/code-review/`.
